This repository contains community-written scripts that read publicly
reachable web pages. It hosts no manga, images or other copyrighted works,
and links to none beyond the site address each script needs in order to
work.

- The scripts are provided as-is, with no warranty. Each one runs only on
  the machine of a user who installs and approves it, against sites that
  user chooses to visit.
- Nothing here is affiliated with, endorsed by, or speaks for any site a
  script reads, nor any of the rights holders of works those sites carry.
  Claims about a site's content belong to that site; they are not this
  repository's to make or answer for, nor the Leaf application's.
- Leaf is a separate project. It ships no scripts, does not name or link
  this repository, and works without it.
- If you are a site operator or rights holder and want a script that reads
  your site removed, open an issue naming the file. Scripts are removed on
  request.
